# YxMod5 项目使命说明

## 项目标识

- **项目名称**：YxMod5
- **目标游戏**：《人类一败涂地》（Human: Fall Flat，Unity 引擎，Steam 平台）
- **项目类型**：游戏模组（Mod）插件
- **文档语言**：中文

## 一句话使命

为《人类一败涂地》提供一个**精简、稳定、多人兼容**、**完全自研（不依赖第三方注入/补丁库）**的模组框架与核心功能集。

## 背景与动机

- 参照项目 `YxModDll`（本地 `F:\VS项目\人类一败涂地\github\YxModDll`）提供了丰富的功能与成熟 UI，但依赖 HarmonyX、Mono.Cecil、MonoMod 等第三方扩展库，架构较重。
- 参照项目 `HumanModLauncher`（`github.com/yxmod/HumanModLauncher`）提供了基于原生代理 DLL 的启动/注入方式，但当前宿主为 `cryptbase.dll`。
- YxMod5 的目标是在保留参照项目**核心体验**的前提下，**重做架构**：功能上做减法（精选核心子集），工程上做减法（自研替代第三方），启动链上做优化（更合适的代理 DLL 宿主）。

## 项目定位与范围

### v1 定位

**精选核心功能子集**，而非对 YxModDll 的全量复刻。优先交付一条完整可用的「启动 → 注入 → UI → 核心能力 → 发布」链路，再在后续版本迭代扩展功能。

### v1 范围（In Scope）

1. **启动链**：原生代理 DLL 引导 → 加载 Unity Mono → 调用 C# 入口 → 挂载模组宿主。
2. **自研运行时基础**：反射访问器层、MonoBehaviour 生命周期驱动、软补丁（状态修正）、事件订阅、配置系统、热键系统、日志系统。
3. **IMGUI UI 框架**：顶部主栏 + 菜单/功能/玩家/设置等分面板，可拖拽、可显隐。
4. **核心玩家能力**：飞天、超级跳、闪现、超人。
5. **分身与传送**：本地分身（增/删/切/控）、定点、玩家间传送。
6. **聊天增强**：彩色发言、表情、聊天记录、自研聊天指令框架。
7. **皮肤与动画**：皮肤模块、动作/动画播放。
8. **辅助 HUD**：小地图、FPS/测速、玩家透视/标记、物体列表。
9. **娱乐模式**：躲猫猫、感染模式。
10. **管理与权限**：黑名单、权限记忆、踢人列表。
11. **发布**：自动更新（GitHub Release）、打包与安装文档。

### v1 范围（Out of Scope / 明确不做）

- 全量复刻 YxModDll 的全部功能（如全景截图、AI 机器人、脚本管理器、图片聊天等，视后续版本再评估）。
- 引入任何第三方方法注入/补丁库（HarmonyX、Mono.Cecil、MonoMod 等）。
- 绕过反作弊、破坏游戏平衡之外的恶意功能（本项目定位为玩家便利与娱乐增强，不提供外挂性质的竞技作弊）。

## 核心原则

1. **自研可控**：注入、补丁、运行时扩展全部自主实现，不依赖第三方补丁库，降低断供与兼容风险。
2. **精简优先**：功能做减法，v1 只保留高频核心功能，保证可维护性与稳定性。
3. **多人兼容**：所有功能从架构层就考虑多人联动（房主/客户端、同步协议、权限校验），不做"单机可用、多人崩溃"的半成品。
4. **稳定优先**：所有反射访问与运行时操作必须做空引用/异常防护，单功能故障不得拖垮整个模组。
5. **可观测**：内置日志与控制台输出，便于定位问题。

## 目标与成功标准（v1）

- 玩家将模组文件放入游戏目录后，启动游戏即可自动注入并显示模组 UI（免手工操作）。
- 核心能力（飞天/超跳/闪现/超人）在单机与多人（房主）场景下稳定可用，且不导致崩溃。
- UI 框架开箱即用，新增一个功能面板的成本低（注册式）。
- 全部能力支持配置持久化（INI/PlayerPrefs）。
- 发布链路打通：能从源码构建 → 打包 → 自动更新 → 玩家下载安装。
